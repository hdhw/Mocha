BAN APPEAL
-----------------------------------------------------------
GET  /api/banappeal/generateCode                    [ADDED]
  The game client's own direct call when it detects your account is
  banned in-app. Mirrors the website's existing recnet/api/banappeal
  version exactly - generates (or reuses) a 10-character appeal code
  tied to the ban record, returns { code, appealUrl, alreadySubmitted }.


-----------------------------------------------------------
AGE VERIFICATION (implemented earlier in the session, listed for completeness)
-----------------------------------------------------------
POST /api/ageverification/generatecode               [ADDED]
  Generates a random 6-char code for the logged-in player, returns
  { ActionCode, VerificationUrl } - the exact two fields the client's
  JuniorAccountAgeVerifyModel deserializes (confirmed by decompiling the
  game's own metadata). Player takes the code to the website to submit a
  photo for manual staff review; approving in the admin panel clears
  their Junior flag.
